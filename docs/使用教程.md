## 一、项目能做什么

纵横风向标每天自动完成这些事：

1. **抓取纵横中文网全部 10 个排行榜**（月票 / 24小时畅销 / 新书 / 点击 / 推荐 / 捧场 / 完结 / 新书订阅 / 24小时更新 / 作者人气）
2. **自动发现每个榜单的分类**（玄幻奇幻、武侠仙侠、都市、历史、科幻、现代言情、游戏、N次元……），每分类抓取 **Top 30**
3. **趋势对比**：新上榜 / 掉榜 / 名次涨跌 / 指标增长 / 当日更新率
4. **深度信号**：动能分（排名×涨幅复合分）、黑马检测（新上榜进前列或单日暴涨）、跨榜影响力（一本书同时在几个榜）
5. **AI 风向日报**：全站日报 + 每分类速评（不配 API 也有规则文案）
6. **部署成在线看板**：GitHub Pages 免费托管，商务级液态玻璃 UI

全部流程跑在 GitHub Actions 上，**你不需要服务器、不需要装任何东西**。

## 二、三分钟上线看板

### 1. Fork

打开 [github.com/siweimidu/ZongHengRankTracker](https://github.com/siweimidu/ZongHengRankTracker)，点右上角 **Fork** → **Create fork**。

### 2. 开启 Pages

进入你 Fork 后的仓库：

- **Settings** → 左侧 **Pages**
- Source 选 **Deploy from a branch**
- Branch 选 `main` / `/ (root)` → **Save**

> 每日 workflow 也会自动部署 Pages（用 Actions 方式），这一步是为了让页面立即可用。

### 3. 首次运行

- 仓库顶部 **Actions** 标签 → 左侧选 **Daily ZongHeng Rank Scraper**
- 右侧 **Run workflow** → 保持默认 → 点绿色 **Run workflow** 按钮
- 等 2~3 分钟，出现绿色 ✅
- 打开 `https://<你的用户名>.github.io/ZongHengRankTracker/` 看板已上线 🎉

### 4. 之后呢？

**什么都不用做。** 每天 UTC 18:20（北京时间凌晨 02:20）自动运行；快照日期按北京时间记录。第二天起，看板上会出现真实的趋势对比信号。

## 三、配置 AI 风向分析（可选）

默认使用基于规则的计算文案。想让日报更有「人味」，接入任意 OpenAI 兼容大模型：

### 步骤

1. 仓库 → **Settings** → **Secrets and variables** → **Actions**
2. 点 **New repository secret**，依次添加三个：

| Name | Value 示例 | 说明 |
|---|---|---|
| `API_BASE_URL` | `https://api.openai.com/v1` | 接口地址（注意带 `/v1`） |
| `API_KEY` | `sk-xxxx...` | 你的密钥 |
| `API_MODEL` | `gpt-4o-mini` | 模型名 |

### 常见服务商配置对照

| 服务商 | API_BASE_URL | 推荐 API_MODEL |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Moonshot 月之暗面 | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| OneAPI / 自建网关 | 你的网关地址 | 按网关配置 |

3. 配好后去 **Actions** → **Force Update (Re-scrape + Re-summarize)** → **Run workflow**，勾选「强制重新生成 AI 分析」，即可看到 AI 日报效果。

> 💡 成本参考：每天约 10 榜 × 12 分类 + 1 篇日报 ≈ 120 次短文本请求，用 gpt-4o-mini / glm-4-flash 级别模型每天成本不到 1 美分。

## 四、看板功能详解

### 看板主页（index.html）

| 区域 | 功能 |
|---|---|
| 顶部玻璃导航 | 品牌 Logo（弹性悬停）· 风向趋势入口 · GitHub |
| 深藏青 Hero | 数据日期 · 追踪榜单数 · 覆盖作品数 · 今日新上榜 · 当日更新率 |
| AI 风向日报 | 打字机效果逐字输出全站日报 |
| 榜单 Tabs | 10 个榜单一键切换（弹性胶囊按钮） |
| 分类 chips | 「全部」+ 自动发现的分类，带数量角标 |
| 工具栏 | 书名/作者/简介搜索 · 名次/热度排序 · 卡片/列表双视图 |
| 趋势速评条 | 当前榜单+分类的 AI/规则速评与新上榜统计 |
| 书籍卡片 | 前三名金银铜徽章 + 皇冠 · 分类/完结标签 · 指标 · 「新」「↑3」「今日更新」旗标 · 金色动能条 |
| 今日黑马 | 新上榜即进前列 / 单日暴涨 ≥8 位的作品 |
| 跨榜影响力 Top15 | 同 时上榜多个榜单的全能作品，含各榜名次胶囊 |

### 风向趋势页（trend.html）

- **分类热度指数**：Top10 数量 + 头部指标对数加权，看哪个分类声量最大
- **高频题材关键词**：基于书名+简介命中统计（系统/重生/穿越/规则怪谈…）
- **榜首时间轴**：历史每日 Top3（数据积累后更有洞察）
- **黑马信号**：本榜黑马卡片

### 作品情报页（book.html）

点击任意书籍卡片进入：封面大图 · 简介 · 完结状态 · **跨榜表现**（该书在全站各榜单的名次/指标/更新状态）· 原著直链。

## 五、数据接口调用

所有数据都是静态 JSON，直接 fetch：

```javascript
// 榜单索引
const boards = await fetch('api/boards.json').then(r => r.json());

// 某榜单全量数据（含趋势分析）
const click = await fetch('api/click/latest/all.json').then(r => r.json());

// 某榜单单分类
const xuanhuan = await fetch('api/click/latest/玄幻奇幻.json').then(r => r.json());

// AI 风向日报 / 跨榜影响力
const brief = await fetch('api/market-brief.json').then(r => r.json());
const cross = await fetch('api/cross-board.json').then(r => r.json());
```

> 提示：分类文件名即中文分类名（URL 编码即可）；`全部` 分类 = `api/<slug>/latest/全部.json`。

## 六、本地运行与开发

```bash
git clone https://github.com/<你的用户名>/ZongHengRankTracker.git
cd ZongHengRankTracker
pip install -r requirements.txt        # 只有 requests

# 抓取（默认每分类 Top 30）
python scrape_zongheng.py

# 参数
python scrape_zongheng.py --top 50        # Top 50
python scrape_zongheng.py --only click end  # 只抓点击榜+完结榜
python scrape_zongheng.py --workers 2     # 降低并发（网络差时）
python scrape_zongheng.py --build         # 抓完顺带构建

# 构建（生成 data/latest_ranks.json 和 api/）
python scripts/build_latest.py            # --force 重生成 AI

# 带 AI 构建
pip install openai
set API_BASE_URL=https://api.deepseek.com/v1   # Windows cmd
set API_KEY=sk-xxxx
set API_MODEL=deepseek-chat
python scripts/build_latest.py
# (Linux/macOS 用 export 代替 set)

# 本地预览看板
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 七、进阶自定义

### 增减榜单

编辑 `zh_tracker/config.py` 的 `BOARDS` 数组，每个榜单一个字典：

```python
{
    "slug": "click",           # 目录名/接口名
    "name": "点击榜",           # 显示名
    "rankType": 5,             # 官网 API 榜单编号
    "period": 0,               # 0=周榜 1=日榜 2=月榜
    "enabled": True,           # False 则跳过
}
```

> 如何找新 rankType：打开纵横 rank 页 → F12 Network → 筛选 `rank/details` → 切换榜单观察表单参数。

### 调整每日抓取量

改 `.github/workflows/scrape.yml` 中的 `--top 30` 为任意值（官网单榜最多 200）。

### 自定义题材关键词

`zh_tracker/config.py` 的 `KEYWORDS` 列表 —— 趋势页的题材热度统计基于它。

### 修改 UI 主题

`css/style.css` 顶部 `:root` 变量集中管理全部设计 token：主色 `--primary`、金色 `--gold`、涨红 `--up`、跌绿 `--down`、玻璃透明度、圆角、弹性缓动曲线。

## 八、故障排查

| 症状 | 原因与解法 |
|---|---|
| Actions 红色失败 | 点进日志看步骤。网络抖动 → Retry；官网接口变更 → 提 issue |
| 看板空白 | 确认 Actions 至少成功跑过一次（`api/` 目录有文件）；确认 Pages 分支/目录配置 |
| 卡片无封面 | 官网封面 CDN 偶尔抽风，看板已做优雅降级 |
| AI 日报是规则文案 | 检查三个 Secret 是否配齐；或当次 AI 调用失败自动兜底，用 Force Update 重试 |
| 分类数量变化 | 正常现象 —— 分类是从数据自动发现的，官网数据源变化会如实反映 |
| 想重抓今天数据 | Actions → **Force Update** → 勾选「重新抓取」→ Run |
